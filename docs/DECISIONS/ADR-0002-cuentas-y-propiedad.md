# ADR-0002 — Cuentas y propiedad

- **Estado:** propuesta
- **Fecha:** 2026-10-29

## Decisión

El dominio, Cloudflare, el perfil de Google y Search Console se crean con el correo del negocio, a nombre del cliente. El desarrollador entra como miembro o usuario. El repositorio se transfiere al cliente (o se le da acceso de dueño) al pagar el saldo. No se guardan secretos en el repositorio; la web no necesita ninguno.

## Consecuencias

- Otro profesional puede continuar el mantenimiento sin depender del desarrollador.
- El cliente es responsable de renovar el dominio cada año.
